## Goal
Tests for the import pipeline. Use real EPUB/MOBI test fixtures from the v1 library (copy a few small ones into `testdata/`).

## Test files
- `internal/importer/epub_test.go` — test metadata extraction from real EPUBs
- `internal/importer/mobi_test.go` — test metadata extraction from real MOBIs
- `internal/importer/audio_test.go` — test with sample audio files or mocked dirs
- `internal/importer/matcher_test.go` — test matching logic (uses in-memory store)
- `internal/importer/importer_test.go` — integration test of full pipeline

## Test fixtures
Create minimal test fixtures in `internal/importer/testdata/`:
- A small valid EPUB with known metadata
- A small valid MOBI with known metadata
- Or generate synthetic ones programmatically

## Coverage
- EPUB: title, author, series, series_index, ISBN, cover, language, description
- MOBI: title, author, ISBN, cover
- Matcher: new work creation, existing work matching, author dedup, series dedup
- Duplicate detection by hash
- Bulk import from directory
