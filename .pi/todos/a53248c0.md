## Goal
Implement the first-run setup flow and login/logout handlers.

## First-run setup (DESIGN_V2.md §4)
- On first launch with empty users table → redirect all routes to `/setup`
- `GET /setup` — form: admin username, password, confirm password, library name
- `POST /setup` — validate, create admin user (bcrypt hash), create library, create session cookie, redirect to `/admin/import`
- Only works when no users exist (prevent re-running setup)

## Login
- `GET /login` — login form (username + password + remember me checkbox)
- `POST /login` — validate credentials, create HMAC session cookie, redirect to `/`
- Show errors inline (wrong password, user not found)

## Logout
- `GET /logout` — clear session cookie, redirect to `/login`

## Templates
- `templates/setup.html`
- `templates/login.html`
- Both use base layout but minimal nav (no library links before setup)

## Guest access
- If `allow_guests: true` in config, unauthenticated users can browse/read/download
- Admin routes always require auth
