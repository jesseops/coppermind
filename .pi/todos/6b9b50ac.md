## Goal
Implement `internal/store/migrate.go` with the full DDL from DESIGN_V2.md §3 and a migration runner.

## Tables (from design)
- `users`
- `authors`
- `series`
- `works`
- `work_authors`
- `work_tags`
- `editions`
- `tracks`
- `reading_states`
- `user_ratings`
- `shelves`
- `shelf_works`
- `libraries`
- `schema_version`

## Migration approach
- Version-based (like v1): `schema_version` table with integer version
- Each migration is a numbered function
- `RunMigrations(db *sqlx.DB) error` applies all pending migrations
- Version 1 = initial schema (all tables above)
- Include indexes from design (library_id, status, author sort_name, work sort_title, edition file_hash)

## SQLite configuration
- WAL mode
- busy_timeout = 5000
- foreign_keys = ON

## Key differences from v1
- v1 used `addColumnIfMissing` hacks — v2 uses clean versioned migrations
- v1 had a single `items` table — v2 has proper Work/Edition split
