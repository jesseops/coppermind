## Goal
Final polish: Dockerfile, docker-compose, CI, and documentation.

## Dockerfile
- Multi-stage build: Go builder + Alpine runtime
- Build Tailwind CSS in builder stage
- Single binary + embedded assets
- Expose port 5000
- Volume mount for data dir
- Non-root user

## docker-compose.yml
```yaml
services:
  coppermind:
    build: .
    ports:
      - "5000:5000"
    volumes:
      - ./data:/data
    environment:
      - COPPERMIND_DB=/data/coppermind.db
      - COPPERMIND_DATA_DIR=/data
      - COPPERMIND_HOST=0.0.0.0
```
