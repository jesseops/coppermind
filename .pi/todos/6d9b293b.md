## Goal
Implement SQLite store methods for editions, tracks, reading states, ratings, shelves, and tags.

## Files
- `internal/store/editions.go`
- `internal/store/tracks.go`
- `internal/store/reading_states.go`
- `internal/store/shelves.go`
- `internal/store/tags.go`

## Editions
- CreateEdition, GetEdition, ListEditions (by work_id), UpdateEdition, DeleteEdition
- FindEditionByHash: for dedup detection during import
- ListEditionsByLibrary: for OPDS/download pages

## Tracks
- CreateTrack, ListTracks (by edition_id, ordered by track_index)
- ReplaceTracksForEdition: delete all + insert (in transaction)
- GetTrack: by ID (for serving audio files)

## Reading states
- GetReadingState(userID, editionID): returns state or nil
- SaveReadingState: upsert (INSERT ... ON CONFLICT DO UPDATE)
- ListReadingStates(userID, status): for "currently reading" view
- ListReadingStatesForWork(userID, workID): all editions of a work the user has progress on

## Shelves
- CreateShelf, GetShelf, ListShelves (by userID), UpdateShelf, DeleteShelf
- AddToShelf, RemoveFromShelf: manage shelf_works join
- ListShelfWorks: works in a shelf with pagination

## Tags
- AddTag, RemoveTag, ListTags (by workID)
- ListAllTags(libraryID): distinct tags across a library with counts

## User ratings
- SaveRating(userID, workID, rating, review): upsert
- GetRating(userID, workID): single lookup
- ListRatings(workID): all ratings for a work
