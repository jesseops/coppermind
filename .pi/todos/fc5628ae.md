## Problem
`downloadCover` in `covers.go` fetches any URL an admin provides. This enables
SSRF — probing internal IPs, cloud metadata endpoints, etc.

## Fix
- Validate cover URLs against an allowlist of domains: `covers.openlibrary.org`
  (and potentially others we add later like Google Books, LibraryThing)
- Add `func isAllowedCoverURL(rawURL string) bool` that parses the URL and
  checks the host against the allowlist
- Call it in both `handleAdminCoverApply` (for URL-based applies) and
  `downloadCover`
- Also applies to `handleAdminCoverSearch` — validate thumb/cover URLs in results

## Scope
- `internal/web/covers.go`
- ~15 lines added
