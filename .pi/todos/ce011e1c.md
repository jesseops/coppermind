## Goal
Implement the library home page and work detail page — the core browse experience.

## Home page (`GET /`)
- Handler: `internal/web/handlers/library.go`
- Shows works grid (cover + title + author + format badges [EPUB] [AUDIOBOOK])
- Recently added by default
- Search bar (HTMX: `hx-get="/?q=..."` with `hx-trigger="keyup changed delay:300ms"`)
- Filter by type: All / Ebooks / Audiobooks
- Sort: Recently Added / Title / Author / Series
- Pagination (50 per page)
- Mobile-first: 2-column grid on phone, 4-6 on desktop
- HTMX partial: items grid swaps without full page reload

## Work detail (`GET /works/:id`)
- Handler: `internal/web/handlers/library.go`
- Work metadata: title, authors (linked), series (linked with position), description, year, language
- Edition cards: one per edition showing format, file size, download button
- For ebooks: "Read" button → `/read/:edition_id`
- For audiobooks: "Listen" button → `/listen/:edition_id`
- Cover image (large)
- Tags list
- User's rating (if logged in)
- Admin: "Edit" link

## Cover serving (`GET /covers/:id`)
- Serve cover image from work.cover_path or edition.cover_path
- Fallback: generate placeholder with initials (port v1's `coverInitials`)
- Cache headers

## Templates
- `templates/base.html` — HTML shell, nav, dark mode toggle, HTMX/CSS includes
- `templates/_nav.html` — navigation partial
- `templates/home.html` — library grid
- `templates/_works_grid.html` — HTMX partial for work cards
- `templates/work.html` — work detail page
