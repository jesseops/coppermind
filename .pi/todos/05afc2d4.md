## Problem
Most web handlers have zero test coverage. Only `send_test.go` (149 lines) tests
the send-to-ereader flow. No tests verify auth enforcement, CSRF, admin gating,
or template rendering.

## Fix
Add integration-style HTTP tests using `httptest.NewServer` with an in-memory store:

### High priority
- Login flow: valid/invalid credentials, session cookie set/cleared
- CSRF enforcement: POST without token → 403, with token → success
- Admin route access: non-admin user → 403, admin → 200
- Cover search with mocked HTTP (inject test HTTP client)

### Medium priority
- Template smoke tests: each page renders without panic given various data
- API JSON format validation
- Profile update, shelf CRUD ownership

### Approach
- Create `internal/web/web_test.go` with a test helper:
  ```go
  func newTestServer(t *testing.T) (*Server, *httptest.Server) {
      store, _ := store.NewMemoryStore()
      cfg := &config.Config{...}
      srv, _ := NewServer(store, cfg)
      return srv, httptest.NewServer(srv)
  }
  ```
- Use `net/http/cookiejar` for session-aware test clients

## Scope
- New file `internal/web/web_test.go` (~300-400 lines)
- New file `internal/web/covers_test.go` (~100 lines)
