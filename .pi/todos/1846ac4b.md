## Overview
Replace the current disconnected browse pages (home, authors, series, author detail,
series detail) with a single unified catalogue component at `/` that supports:

- **Grouping**: None (flat grid), By Author, By Series
- **Sorting**: Recently added, Title A-Z, Author, Year, Series order
- **Filtering**: Type (all/ebook/audiobook), Search, Author ID, Series ID, Shelf ID
- **Views**: Grid (covers, primary) and List (table, secondary — easy toggle)
- **Card actions**: Read/Listen, Send to device, Download, Add to shelf — all inline

## Navigation Changes
- Top nav: `Catalogue | Shelves | Receive` (Shelves hidden or "login required" for anon)
- `/` is the catalogue root (no new URL)
- `/` with `?group=author` replaces `/authors`
- `/` with `?group=series` replaces `/series`
- `/` with `?author={id}` replaces `/authors/{id}`
- `/` with `?series={id}` replaces `/series/{id}`
- `/` with `?shelf={id}` filters to a specific shelf
- Old routes redirect to new query-param equivalents

## Backend Changes
- Add `ShelfID` to `store.WorkFilter`
- Implement shelf filtering in `ListWorks` (JOIN shelf_works)
- Single handler reads all query params → builds WorkFilter + grouping
- For grouped view: fetch all works matching filter, group in-memory by author/series
- Load all at once (no per-group pagination for now)

## Template: `catalogue.html`
- Toolbar: search input, group dropdown, sort dropdown, type dropdown, view toggle (grid/list)
- All controls HTMX-driven with `hx-push-url` for bookmarkable state
- Grid view: current work-card layout but with action menu on hover
- List view: sortable table (title, author, series, year, format, actions)
- Grouped view: collapsible sections with group header + count

## Card Action Menu (grid + list)
- 📖 Read / 🎧 Listen
- 📲 Send to device (opens send-with-code inline)
- ⬇️ Download
- 📚 Add to shelf → submenu with user's shelves

## Shelf Integration
- Nav item "Shelves" → shows user's shelves (each links to `/?shelf={id}`)
- Add-to-shelf via action menu → HTMX POST with inline feedback
- Shelf management (create/delete) accessible from shelves page

## Decisions
- All works loaded at once (pagination as future enhancement)
- Grid is primary view, list is alternative with easy toggle
- Full action set on every card
- Shelves user-specific, hidden or "login required" for anon
- Tag filtering deferred to separate todo

## Scope
- Rewrite: `home.html` → `catalogue.html` (or reuse name)
- Delete: `authors.html`, `series_list.html`, `author_detail.html`, `series_detail.html`
- Update: `base.html` nav, `handlers.go`, `server.go` routes
- New: card action menu component in CSS, shelf add endpoint HTMX response
- Estimated: ~400 lines template, ~100 lines handler, ~50 lines store
