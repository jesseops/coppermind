## Goal
Implement `internal/importer/importer.go` — the orchestrator that ties together format detection, metadata extraction, matching, file copy, cover extraction, and hashing.

## Pipeline (from DESIGN_V2.md §7)
```
Input (file path or upload) 
  → Detect format (EPUB, MOBI, MP3, M4B, PDF)
  → Extract metadata (call epub.go/mobi.go/audio.go)
  → Compute SHA-256 hash
  → Check for duplicates (by hash)
  → Match to existing Work/Author/Series (matcher.go)
  → Copy file to library directory
  → Extract cover art → save as file
  → Create Edition record in DB
  → If audiobook: build track list, create Track records
  → Return ImportResult
```

## Interface
```go
type Importer struct {
    store   store.Store
    dataDir string  // base directory for library files
}

type ImportInput struct {
    SourcePath  string   // local file/dir path
    LibraryID   int64
    // Optional overrides:
    Title       string
    Authors     []string
    Series      string
    SeriesIndex *float64
}

type ImportResult struct {
    Work     *domain.Work
    Edition  *domain.Edition
    IsNew    bool
    Skipped  bool
    SkipReason string
}

func (imp *Importer) Import(ctx context.Context, input ImportInput) (*ImportResult, error)
func (imp *Importer) BulkImport(ctx context.Context, dirPath string, libraryID int64) ([]ImportResult, error)
```
