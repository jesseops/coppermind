## Problem
`handleAdminCoverSearch` in `covers.go` builds HTML via `fmt.Fprintf` with unescaped
Open Library data (`res.Title`, `res.CoverURL`, `res.Author`). Malicious or malformed
data from the API could inject script tags.

## Fix
- Import `html` and use `html.EscapeString()` on all text interpolated into HTML
- Validate `res.CoverURL` and `res.ThumbURL` start with `https://covers.openlibrary.org/`
- Consider switching to a template partial for the search results HTML instead of Fprintf

## Scope
- `internal/web/covers.go` — `handleAdminCoverSearch` function only
- ~20 lines changed
