## Goal
Set up the web server foundation: Chi router, middleware stack, template engine, static file serving, and Tailwind v4 CSS build.

## Files
- `internal/web/server.go` — Server struct, constructor, Chi router setup, middleware registration
- `internal/web/routes.go` — Route registration (all routes from DESIGN_V2.md §5)
- `internal/web/middleware.go` — Security headers, request logging, gzip, CSRF (or use auth/csrf.go)

## Server struct
```go
type Server struct {
    store     store.Store
    importer  *importer.Importer
    config    *config.Config
    templates *template.Template
    secret    []byte  // session signing secret
}
```

## Middleware stack (order matters)
1. RequestID
2. RealIP
3. Request logger (slog)
4. Recoverer
5. Security headers (X-Content-Type-Options, X-Frame-Options, etc.)
6. CSRF protection
7. Gzip
8. OptionalAuth (set user in context if session cookie present)

## Templates
- Use `go:embed` for `templates/` and `static/`
- Base template with common layout
- Template functions: urlquery, coverInitials, formatDate, etc.

## Tailwind v4
- Download standalone CLI binary in Makefile
- `input.css` with @import "tailwindcss" and custom theme vars
- Dark mode: class-based (toggle) with system preference detection via JS
- Theme customization: CSS custom properties for colors
- Build to `internal/web/static/css/app.css`

## Static files
- Serve from embedded FS at `/static/`
- HTMX (download and embed, ~14KB gzipped)
