## Problem
`AllowGuests` config field exists but is never checked. When false, unauthenticated
users can browse the library, download files, read books, and access the full JSON API.

## Fix
- Add `guestGateMiddleware` that checks `s.config.AllowGuests`:
  - If false and no user in context → redirect to `/login` (HTML) or 401 (API/OPDS)
  - Skip for: `/login`, `/logout`, `/setup`, `/static/*`, `/receive/*`
- Apply it in `buildRouter()` to the public routes group
- OPDS/API: Support HTTP Basic Auth in `OptionalAuth` middleware as fallback
  - Parse `Authorization: Basic ...` header, validate against user store
  - This covers OPDS clients (KOReader, etc.) and API consumers

## Decision
→ OPDS requires auth via HTTP Basic Auth when AllowGuests=false.

## Scope
- New middleware in `internal/web/server.go`
- Basic Auth support in `internal/auth/middleware.go`
- Route restructuring in `buildRouter()`
