## Problem
`handleCover`, `handleEditionCover`, `handleDownload`, `handleAudioTrack`, `handleEpubAsset`
all serve files using paths stored in the DB (`work.CoverPath`, `edition.FilePath`, etc.)
with no validation that the path is within the data directory.

## Fix
- Add a helper `func (s *Server) safePath(path string) (string, error)` that:
  1. `filepath.Clean(path)`
  2. Checks `strings.HasPrefix(cleaned, filepath.Clean(s.config.DataDir))`
  3. Returns error if outside data dir
- Call it before every `http.ServeFile` in the 5 affected handlers
- Also apply to `handleReader` → `importer.ExtractEpubChapter(edition.FilePath, ...)`

## Scope
- New helper in `internal/web/server.go` or `internal/web/handlers.go`
- 5-6 handler functions updated
- Add test for traversal attempt
