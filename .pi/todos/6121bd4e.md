## Problem
In `user_handlers.go`, `registerUserRoutes` places shelf mutation routes
**outside** the `RequireAuth` group:

```go
r.Get("/shelves/{id}", s.handleShelfDetail)       // public (OK for public shelves)
r.Post("/shelves/{id}/add", s.handleAddToShelf)    // ⚠️ no auth
r.Post("/shelves/{id}/remove", s.handleRemoveFromShelf)  // ⚠️ no auth
```

Additionally, `handleAddToShelf` and `handleRemoveFromShelf` don't verify the
shelf belongs to the requesting user.

## Fix
1. Move `/shelves/{id}/add` and `/shelves/{id}/remove` into the `RequireAuth` group
2. In both handlers, load the shelf and verify `shelf.UserID == user.ID`
3. For `handleShelfDetail`, check: if shelf is not public, require auth + ownership

## Scope
- `internal/web/user_handlers.go` — route registration + 3 handlers
- ~15 lines changed
