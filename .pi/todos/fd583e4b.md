## Goal
Implement CLI commands using Cobra in `cmd/coppermind/`.

## Files
- `main.go` — just calls `Execute()`
- `root.go` — root command, persistent flags (--config, --db), config resolution
- `serve.go` — `coppermind serve` (was `run` in v1), starts web server
- `import.go` — `coppermind import <path>` and `coppermind bulk-import <dir>`
- `users.go` — `coppermind add-user`, `coppermind reset-password`, `coppermind list-users`
- `init.go` — `coppermind init` (create DB, first library, prompt for admin account)

## Commands

### `coppermind init --name "My Library"`
- Create DB file
- Run migrations
- Create default library
- Prompt for admin username/password (or accept --username/--password flags)

### `coppermind serve [--host] [--port]`
- Load config, start web server

### `coppermind import <path> [--title] [--author] [--series] [--library-id]`
- Import single file or directory

### `coppermind bulk-import <dir> [--library-id]`
- Walk directory, import all supported files

### `coppermind add-user --username <u> --password <p> [--role admin|viewer] [--display-name <n>]`
### `coppermind reset-password --username <u> --password <p>`
### `coppermind list-users`

### `coppermind list [--type books|authors|series] [--library-id]`
### `coppermind search --q <query> [--library-id]`
