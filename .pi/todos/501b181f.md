## Goal
Implement admin pages: import, edit metadata, user management, duplicate detection.

## Import page (`GET/POST /admin/import`)
- Handler: `internal/web/handlers/admin.go`
- File upload form (drag & drop zone + file picker)
- Accept multiple files
- Show import results (success/skip/error per file)
- HTMX: submit uploads, show progress

## Edit work (`GET /admin/works/:id/edit`, `POST /admin/works/:id`)
- Form pre-filled with current metadata
- Edit: title, authors (add/remove), series (select or create), series_index, description, language, year, tags
- Per-edition: edit publisher, ISBN, narrator, notes
- Delete edition
- Delete work (with confirmation)

## User management (`GET /admin/users`)
- List users with roles
- Add user form
- Edit role, reset password
- Delete user (with confirmation)

## Duplicate detection (`GET /admin/duplicates`)
- Port v1's duplicate detection (group by normalized title + author)
- Show groups with merge/delete options
- HTMX actions for merge/delete

## Templates
- `templates/admin_import.html`
- `templates/admin_edit.html`
- `templates/admin_users.html`
- `templates/admin_duplicates.html`
