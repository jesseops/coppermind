## Goal
Implement send-to-Kindle via SMTP email and user shelves/ratings.

## Send to Kindle (`POST /admin/send/:edition_id`)
- Handler: `internal/web/handlers/admin.go`
- Implementation: `internal/sender/kindle.go`
- User configures their Send-to-Kindle email in profile
- Admin configures SMTP settings in config (env vars: COPPERMIND_SMTP_HOST, etc.)
- Compose email with book file as attachment
- Send via SMTP
- Show success/error feedback
- Interface: `internal/sender/sender.go` for future extensibility

## Shelves
- `GET /me/shelves` — list user's shelves
- `POST /me/shelves` — create shelf (name, description, public/private)
- `GET /shelves/:id` — shelf contents (public shelves viewable by all)
- `POST /shelves/:id/add` — add work to shelf (HTMX)
- `POST /shelves/:id/remove` — remove work from shelf

## Ratings
- `POST /me/rate/:work_id` — rate a work (1-5 stars + optional review)
- Show on work detail page
- Average rating display

## User profile (`GET /me`)
- Display name, username
- Kindle email setting
- Change password form
