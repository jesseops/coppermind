## Goal
Implement author and series browse/detail pages.

## Authors browse (`GET /authors`)
- List all authors with work counts, alphabetically by sort_name
- Link each to author detail
- Search/filter

## Author detail (`GET /authors/:id`)
- Author name
- List of works by this author (reuse works grid partial)
- Show role badges if author has different roles (author, narrator, editor)

## Series browse (`GET /series`)
- List all series with work counts
- Link each to series detail

## Series detail (`GET /series/:id`)
- Series name and description
- Works ordered by series_index
- Show series_index numbers (e.g., "#1", "#2", "#2.5")

## Templates
- `templates/authors.html` — author list
- `templates/author.html` — single author detail
- `templates/series_list.html` — series list
- `templates/series.html` — single series detail
