## Goal
Implement `internal/config/config.go` — 12-factor config loading with env var primary and JSON config file fallback.

## Config struct fields
- `DBPath` (COPPERMIND_DB)
- `Host` (COPPERMIND_HOST, default "127.0.0.1")
- `Port` (COPPERMIND_PORT, default 5000)
- `DataDir` (COPPERMIND_DATA_DIR, default "./data")
- `LogLevel` (COPPERMIND_LOG_LEVEL, default "info")
- `LogFormat` (COPPERMIND_LOG_FORMAT, default "text")
- `SessionSecret` (COPPERMIND_SESSION_SECRET, auto-generated if missing)
- `AllowGuests` (COPPERMIND_ALLOW_GUESTS, default false)
- `SMTPHost`, `SMTPPort`, `SMTPUser`, `SMTPPass`, `SMTPFrom` (for Kindle send)

## Behavior
1. Load JSON config file if it exists (check `--config` flag, then `COPPERMIND_CONFIG` env, then `./config.json`, then `~/.config/coppermind/config.json`)
2. Override any field with env vars (env always wins)
3. Apply defaults for missing values
4. Validate required fields

Port v1's `ResolveConfigPath`, `LoadConfig`, `ApplyEnvOverrides` pattern but expand it.
