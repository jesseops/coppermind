## Goal
Implement `internal/auth/` — password hashing, HMAC session cookies, and middleware.

## Files

### `internal/auth/password.go`
- `HashPassword(password string) (string, error)` — bcrypt with default cost
- `CheckPassword(hash, password string) error` — bcrypt compare

### `internal/auth/session.go`
- Session token: HMAC-SHA256 signed cookie containing `userID|expiry|signature`
- `CreateSession(userID int64, rememberMe bool, secret []byte) (string, time.Time)` — returns cookie value and expiry
- `ValidateSession(cookieValue string, secret []byte) (int64, error)` — returns userID or error
- Cookie name: `coppermind_session`
- Default expiry: 24h, remember-me: 30 days
- HttpOnly, Secure (when HTTPS), SameSite=Strict

### `internal/auth/middleware.go`
- `RequireAuth(store, secret)` — middleware that checks session cookie, loads user into context
- `RequireAdmin(store, secret)` — same but also checks role == "admin"
- `OptionalAuth(store, secret)` — sets user in context if logged in, otherwise nil (for guest access)
- Context helpers: `UserFromContext(ctx) *domain.User`, `SetUserInContext(ctx, user) context.Context`

### `internal/auth/csrf.go`
- Double-submit cookie pattern (port from v1's `csrfProtect`)
- Generate CSRF token, validate on POST/PUT/DELETE
