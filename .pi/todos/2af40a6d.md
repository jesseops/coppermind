## Goal
Implement the SQLite-backed Store for libraries and users.

## Files
- `internal/store/sqlite.go` — `SQLiteStore` struct, constructor (`NewSQLiteStore(dbPath string) (*SQLiteStore, error)`), DB open/configure/close
- `internal/store/users.go` — User CRUD methods on `SQLiteStore`
- `internal/store/libraries.go` — Library CRUD methods on `SQLiteStore`

## SQLiteStore constructor
- Open DB with modernc.org/sqlite
- Configure WAL, busy_timeout, foreign_keys
- Run migrations
- Return store instance

## User methods
- CreateUser: insert with bcrypt hash (hash passed in, not computed here)
- GetUser, GetUserByUsername: single-row queries
- ListUsers: all users ordered by username
- UpdateUser: partial update (display_name, password_hash, role)
- DeleteUser: hard delete (cascade reading_states, shelves, etc.)

## Library methods
- CreateLibrary: insert, return with ID
- GetLibrary: by ID
- ListLibraries: all, ordered by ID
