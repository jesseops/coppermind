## Goal
Implement audio file metadata extraction in `internal/importer/audio.go`.

## From v1
- `extractAudioMetadataFromFile` — infer title from filename
- `extractAudioMetadataFromDir` — infer title from directory name
- `inferAudioFormatFromDir` — detect mp3/m4b from dir contents
- `containsAudioFiles`, `isAudioExt`
- `buildAudiobookTracks` — enumerate audio files in dir, create track list

## Enhancements for v2
- Consider using a lightweight ID3/MP4 tag reader to get actual metadata (title, artist/author, album) rather than just filename inference
- If no good pure-Go library exists, filename inference is fine for launch (note: v1 doesn't read ID3 tags either)
- Return `metadata.Extracted` struct
- Build track list with proper ordering (natural sort on filenames)
