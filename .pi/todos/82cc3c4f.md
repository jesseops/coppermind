## Problem
HTMX forms use per-form hidden `csrf_token` fields. This works but is verbose
and error-prone (easy to forget in new forms). The HTMX-idiomatic approach is
to set a global header.

## Fix
- In `base.html`, add to the `<body>` tag:
  ```html
  <body hx-headers='{"X-CSRF-Token":"{{.CSRFToken}}"}'>
  ```
- Remove hidden `csrf_token` fields from all HTMX-submitted forms
- Keep hidden fields ONLY in standard HTML form submissions (login, setup, admin edit,
  profile update — forms that submit without HTMX)

## Decision
→ Clean up. Less code is better.

## Scope
- `base.html` — 1 line change on body tag
- Remove hidden fields from ~8 HTMX forms across templates
