## Goal
Initialize the Go project with module path `github.com/jesseops/coppermind`, create the full directory tree from DESIGN_V2.md §9, set up go.mod with dependencies, and create a Makefile.

## Dependencies
- github.com/go-chi/chi/v5
- github.com/jmoiron/sqlx
- github.com/spf13/cobra
- modernc.org/sqlite
- golang.org/x/crypto (bcrypt)

## Makefile targets
- `make build` — build binary to `bin/coppermind`
- `make test` — run all tests
- `make test-v` — verbose tests
- `make lint` — run go vet
- `make clean` — remove build artifacts
- `make css` — build Tailwind CSS (placeholder for now)
- `make dev` — build + run with hot-reload or just build+run
- `make all` — css + build

## Decisions captured
- Module: `github.com/jesseops/coppermind`
- Config: env vars primary, flat JSON config file secondary (12-factor)
- Sessions: HMAC-signed cookies
- EPUB: server-side rendering
- Multi-library: schema-aware but single default library for now
- Tailwind: v4 standalone CLI
- Theme: dark mode toggle + system theme support built in from start
