## Goal
Integrate send2ereader-style wireless book transfer into Coppermind. Users open the e-reader's browser to a page on the server, get a 4-char code, then use the "Send via..." dropdown on any edition to send the file to the e-reader wirelessly.

## Core mechanism
- In-memory key store with auto-expiry (~30s after last poll)
- `/receive` page: detects Kobo/Kindle/Tolino User-Agent, generates key, polls for files
- `/send/{edition_id}` POST with key: associates file with key, optionally converts
- Status polling endpoint, file download gated by key

## Conversion
- EPUB → KEPUB using pgaskin/kepubify Go library (no external binary)
- Skip KindleGen (modern Kindles accept EPUB)

## UI changes
- Edition cards on work detail page: "Send via..." dropdown alongside Read/Download
  - "Send with code" — opens modal/inline form to enter 4-char key
  - "Send to Kindle" — existing email feature
- `/receive` page for e-reader browsers: shows key, polls for download

## Sub-tasks
1. Add `pgaskin/kepubify` dependency
2. Implement `internal/web/send.go` — key store, generate/status/upload/download handlers
3. Implement `/receive` page template (e-reader facing)
4. Add "Send via..." dropdown to work detail edition cards
5. Add send-with-code modal/form
6. Wire up KEPUB conversion for Kobo devices
7. Tests
