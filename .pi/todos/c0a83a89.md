## Problem
Several admin and user features exist as backend routes but are not discoverable
in the UI — there are no links to them from the main navigation or expected places.

## Missing Links / Pages to Audit

### Admin (visible only to admin users)
- **User management** (`/admin/users`) — No link from anywhere after initial setup.
  Should be in an admin dropdown or admin section.
- **Bulk import** (`/admin/import`) — Only linked in nav when logged in as admin,
  but could be more prominent with drag-and-drop, directory scan, etc.
- **Duplicates** (`/admin/duplicates`) — Stub page, no link anywhere.
- **Work editing** (`/admin/works/{id}/edit`) — Only accessible from work detail.
  In list view, should have a quick-edit link per row.

### User
- **Shelves** (`/me/shelves`) — Not in main nav. Should be a top-level nav item.
- **Profile** (`/me`) — Only accessible by clicking display name. Fine but could
  be clearer.
- **Currently Reading** (`/me/reading`) — In nav, but the reading state isn't being
  updated (see separate todo). Empty state should explain what it does.

### Proposed Admin Section
Add an admin dropdown in nav (gear icon or "Admin" text):
- Import books
- Manage users
- Duplicate detection
- (Future: library settings, scheduled tasks)

### Proposed User Section
- Shelves in main nav (or sub-nav)
- Clear empty states explaining features
- Profile accessible from user dropdown

## Scope
- `base.html` nav template changes
- Possibly a new `admin_dashboard.html` landing page
- Route audit to ensure nothing is orphaned
