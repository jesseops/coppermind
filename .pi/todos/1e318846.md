## Problem
Throughout handlers, errors from store methods are discarded with `_`:
```go
editions, _ := s.store.ListEditions(id)
tags, _ := s.store.ListTags(id)
works, _, _ := s.store.ListWorks(...)
```
A database error silently produces empty pages instead of a 500.

## Fix
- Audit all handlers in `handlers.go`, `user_handlers.go`, `opds_handlers.go`, `api.go`
- For critical paths (the data the page is about), return 500 on error
- For supplementary data (tags on a work page, edition counts), log and continue
- Pattern:
  ```go
  editions, err := s.store.ListEditions(id)
  if err != nil {
      slog.Error("list editions", "work_id", id, "err", err)
      http.Error(w, "Internal Server Error", 500)
      return
  }
  ```
- For API handlers, return `{"error":"internal error"}` JSON

## Scope
- ~40 instances across 4 files
- No behavior change when DB is healthy, better behavior when it isn't
