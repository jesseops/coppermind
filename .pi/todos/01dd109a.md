## Problem
Tags/genre/subject data exists in the schema (`work_tags` table) and can be populated
via the metadata lookup feature, but there's no way to filter the catalogue by tag.

## When Ready
After the unified catalogue is built, add:
- Multi-select tag filter (chips or dropdown with checkboxes)
- `Tag string` field on `WorkFilter`
- JOIN `work_tags` in `ListWorks` when tag filter is active
- Tags displayed on work cards (small pills below author)
- Tag cloud or sidebar facet showing available tags with counts
- Possibly: auto-suggest tags as user types in the filter

## Also Consider
- Bulk tag management (admin: tag/untag multiple works at once)
- Tag hierarchy or synonyms (e.g., "sci-fi" = "science fiction")
- Import tags from EPUB metadata subjects during import (already partially done)
