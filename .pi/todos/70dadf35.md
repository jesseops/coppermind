## Problem
`strings.Title` has been deprecated since Go 1.18. It doesn't handle Unicode
correctly (e.g., Dutch "ij" digraph).

## Fix
- Add `golang.org/x/text` dependency
- Replace `"title": strings.Title` in `server.go` FuncMap with:
  ```go
  "title": cases.Title(language.English).String
  ```
- Import `golang.org/x/text/cases` and `golang.org/x/text/language`

## Scope
- `internal/web/server.go` — 1 line + import
- `go get golang.org/x/text`
