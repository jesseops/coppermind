Send to E-Reader

Open this page on your Kobo, Kindle, or Tolino e-reader's built-in web browser. A unique code will appear. Then use the "Send with code" option on any book to transfer it wirelessly.

How it works

  1. On your e-reader, open the web browser
  2. Navigate to
  3. A 4-character code will appear (e.g., A3KR)
  4. On this device, find a book and click "Send via… → Send with code"
  5. Enter the code and click Send
  6. The book will appear as a download on your e-reader

For Kobo devices, EPUB files can be automatically converted to Kobo's optimized KEPUB format. Files are stored temporarily and deleted shortly after the e-reader disconnects.
